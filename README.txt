JOMAAIR website - upload steps (GitHub Pages)
1. Create a repository and upload EVERYTHING in this folder (index.html, other .html files, css folder, images folder, .nojekyll).
2. The two photos are already in the images folder (petrochemical.jpg and conference.jpg).
3. Repository Settings > Pages > Deploy from branch > main > / (root).
4. Search for "[editorial email address to be added]" in the .html files and replace it with the real email.
5. When you buy the GoDaddy domain, add it under Settings > Pages > Custom domain.
